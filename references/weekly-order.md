# 整周点餐详细说明

> 本文档是 SKILL.md --week 参数的详细补充，包含智能日期计算逻辑、使用场景和输出示例。

## 功能概述

`--week` 参数用于智能计算并点餐本周剩余天数或下周整周（周一到周五）所有餐。

**主要用途**：
- 周日提前安排下周餐食
- 周中补充本周剩余天数餐食
- 一次性安排多天餐食，减少手动操作

---

## 智能日期计算逻辑

脚本根据当前日期自动计算目标日期列表：

| 执行日期 | 目标日期 | 天数 | 说明 |
|---------|---------|------|------|
| **周日** | 下周周一到周五 | 5天 | 提前安排下周餐食 |
| **周六** | 下周周一到周五 | 5天 | 周六通常无时段，为下周准备 |
| **周一** | 本周周一到周五 | 5天 | 包含今天，本周完整周 |
| **周二** | 本周周二到周五 | 4天 | 包含今天，本周剩余天数 |
| **周三** | 本周周三到周五 | 3天 | 包含今天，本周剩余天数 |
| **周四** | 本周周四到周五 | 2天 | 包含今天，本周剩余天数 |
| **周五** | 本周周五 | 1天 | 仅今天 |

### 计算规则

```python
weekday = today.weekday()  # 周一=0, ..., 周日=6

if weekday >= 5:  # 周六或周日
    # 点下周周一到周五
    days_until_monday = 7 - weekday if weekday == 6 else 2
    for i in range(5):
        date = today + timedelta(days=days_until_monday + i)
else:
    # 点本周剩余天数（今天到周五）
    remaining_days = 5 - weekday
    for i in range(remaining_days + 1):  # +1 包含今天
        date = today + timedelta(days=i)
```

## 参数组合

### 与 --exclude 组合

**用途**：整周点餐时排除特定菜品

**示例**：
```bash
# 点整周，排除辣和炸的菜品
python <SKILL_DIR>/scripts/order_meal.py --week --exclude "辣|炸"
```

### 与 --expect 组合

**用途**：整周点餐时指定关键字菜品

**示例**：
```bash
# 点整周，优先选含鸡腿或牛肉的菜品
python <SKILL_DIR>/scripts/order_meal.py --week --expect "鸡腿|牛肉"
```

### 与 --list 组合

**用途**：仅列出本周剩余可点餐日期，不下单

**示例**：
```bash
# 仅显示本周剩余可点餐日期
python <SKILL_DIR>/scripts/order_meal.py --week --list
```

**输出**：
```
[整周模式] 本周剩余天数：4 天
[整周模式] 点餐日期：
  1. 2026-06-03（周二）
  2. 2026-06-04（周三）
  3. 2026-06-05（周四）
  4. 2026-06-06（周五）

[提示] --list 模式下仅显示日期，不执行点餐
```

## 参数冲突处理

### 与 --date 冲突

**处理规则**：忽略 `--date`，使用 `--week` 模式

**示例**：
```bash
# 同时传 --week 和 --date，忽略 --date
python <SKILL_DIR>/scripts/order_meal.py --week --date "+1"

# 实际执行：整周点餐模式
```

### 与 --tab 冲突

**处理规则**：报错退出

**原因**：整周模式需点三餐，不支持指定时段

**示例**：
```bash
# 同时传 --week 和 --tab，报错
python <SKILL_DIR>/scripts/order_meal.py --week --tab "午餐"

# 输出：
# [错误] 整周模式需点三餐，不支持指定时段（--tab）
```

## 已下单检查机制

### 自动避免重复下单

脚本对每一天检查已下单状态：

1. 查询美餐 API 获取线上订单状态
2. 对每个时段（早/午/晚）检查是否已下单
3. 仅对未下单时段执行点餐
4. 已下单时段以 `[已有订单]` 标签显示

### 与每日点餐的配合

**场景**：
- 周日执行 `--week` → 点下周周一到周五
- 周一执行 `--date "+1"` → 点周二

**结果**：
- 周一的命令检测到周二已下单（周日已点）
- 输出：`[已有订单][周二] ...`
- 自动跳过，不重复下单

## Timeout 建议

**建议 timeout**：7200 秒（约 2 小时）

**计算依据**：
- 最长情况：点 5 天 × 3 餐 = 15 餐
- 每餐下单耗时：约 30-60 秒（网络延迟）
- 总耗时预估：15 × 60 = 900 秒（约 15 分钟）
- 留有余量：7200 秒（覆盖特殊情况）

## 常见问题

### Q1：周六执行 --week 会怎样？

**回答**：周六通常无可点餐时段，但脚本会智能计算下周周一到周五，为下周准备餐食。

### Q2：如果本周部分餐已下单？

**回答**：脚本自动检测已下单状态，仅补充未下单的餐，不会重复下单。

### Q3：整周点餐失败怎么办？

**回答**：脚本会输出详细的失败报告，包含每天每餐的下单结果，方便排查问题。

### Q4：可以指定只点某些天吗？

**回答**：不行，`--week` 是智能计算，会根据当前日期自动确定目标日期。如需指定特定日期，请使用 `--date` 参数。
